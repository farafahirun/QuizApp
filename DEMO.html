🎯 Aplikasi Kuis React - Demo & Dokumentasi

🔐 Fitur Login

  • Login sederhana dengan username
  • Auto-detect kuis yang belum selesai
  • Dialog konfirmasi untuk resume
  • Validasi input username

📚 Soal dari OpenTDB

  • 15 soal General Knowledge
  • Tingkat kesulitan: Medium
  • Campuran multiple choice
  • Auto-shuffle pilihan jawaban

⏱️ Timer Countdown

  • Durasi: 5 menit (300 detik)
  • Format: MM:SS
  • Visual indicator (hijau/kuning/merah)
  • Auto-submit saat waktu habis

📊 Progress Tracking

  • Total soal ditampilkan
  • Jumlah yang sudah dijawab
  • Sisa soal yang belum dikerjakan
  • Progress bar visual

📄 Satu Soal Per Halaman

  • Display 1 soal pada satu waktu
  • Auto-next setelah pilih jawaban
  • Feedback visual (hijau/merah)
  • Prevent double-click

💾 Resume dengan LocalStorage

  • Auto-save setiap perubahan
  • Bisa lanjut setelah browser ditutup
  • Simpan waktu, skor, posisi soal
  • Dialog konfirmasi saat login

📈 Halaman Hasil

  • Jumlah benar/salah/dijawab
  • Persentase & Grade (A-E)
  • Emoji & pesan motivasi
  • Tombol Main Lagi & Logout

🎨 UI/UX Modern

  • Design gradient purple modern
  • Responsive (desktop & mobile)
  • Animasi smooth & transisi
  • Loading indicator

🛠️ Tech Stack

React 19 React Router DOM Vite LocalStorage API Open Trivia DB API CSS3 JavaScript ES6+
